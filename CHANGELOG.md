# Изменения

## Не выпущено

- Проверка в настоящем клиенте: CI запускает Qwen Code с сервером, который зарегистрировал `install.py`, —
  клиент должен подключиться к нему и увидеть расширение. `scripts/client_smoke.py` делает то же локально.

## 0.3.0 — 2026-10-22

- Английский и русский (ADR 0004): описания инструментов, ответы, подсказки и вывод `install.py`.
  Язык задаёт `PG_MCP_LANG` или `install.py --lang`, иначе локаль системы; `status` показывает его.
  Модель просят отвечать пользователю на его языке.
- Инструмент `search_schema` во всех профилях: ищет таблицы, представления и колонки по фрагменту имени
  или комментария во всех доступных роли схемах, не больше 100 совпадений. Для больших баз, где
  `list_tables` упирается в 200 записей.
- Журнал запросов агента (ADR 0005): с `PG_MCP_QUERY_LOG` каждый вызов инструмента пишется строкой JSON —
  кто, что, чем кончилось и сколько строк вернул запрос, без самих данных. Файл с правами 600, ссылка
  на его месте отвергается, сбой записи не мешает работе и виден в `status`.
- Подробный README на английском (`README.md`) и русском (`README.ru.md`): установка по шагам для macOS,
  Linux и Windows, примеры ответов, профили, язык, настройки, роль для DBA и разбор частых сбоев.
- Интеграционные тесты в CI на PostgreSQL с 13-й по 18-ю. До 14-й версии таблица без статистики
  неотличима от пустой, и `list_tables` пишет «пусто или статистику ещё не собирали», а не «~0 строк».
- Раскладка по рекомендациям PyPA: пакет в `src/pg_mcp/`, сторонние пакеты в `src/pg_mcp/_vendor/`,
  запуск из клона — `python -I run.py`, после установки — `pg-mcp` или `python -m pg_mcp`.
- `pyproject.toml` с метаданными и настройками инструментов, окружение разработки на uv с `uv.lock`.
- ruff вместо flake8, mypy в режиме strict, тесты на pytest с покрытием по веткам (порог 95%), pre-commit.
- CI на uv: Linux, Windows и macOS под Python 3.9 и 3.14; dependabot для Actions и инструментов.

## 0.2.0 — 2026-10-22

- Инструменты `describe_table`, `sample_rows`, `explain_query` и `run_select`.
- Профили групп `schema`, `explore` (по умолчанию) и `analyst`: `install.py --profile` или `PG_MCP_PROFILE`.
- Политика SQL только на чтение (ADR 0002): проверка текста запроса, транзакция `READ ONLY` с обязательным
  откатом на каждый запрос агента, скрипт роли для DBA `docs/role.sql`.
- Бюджет ответа: каждый ответ укладывается в `PG_MCP_MAX_RESPONSE_CHARS` символов (по умолчанию 8000).
- Ревизия MCP 2026-07-28 без рукопожатия: `server/discover`, версия протокола в `_meta` каждого запроса.
  Клиенты ревизий 2024-11-05 — 2025-11-25 работают, как раньше.
- Подсказки при неверном пароле, несуществующей базе и отказе от TLS.
- Проверка целостности `server/vendor` и flake8 в CI.

## 0.1.0 — 2026-10-22

- Первый срез: протокол MCP на стандартной библиотеке Python 3.9+, инструменты `status` и `list_tables`,
  драйвер pg8000 в репозитории, `install.py` для GigaCode CLI и Qwen Code, расширение с командой `/pg:setup`.
