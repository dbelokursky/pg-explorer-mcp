# pg-mcp

MCP-сервер для PostgreSQL с доступом только на чтение: для GigaCode CLI и других агентов
семейства Qwen Code. Написан на Python 3.9+ без внешних зависимостей: драйвер pg8000 лежит
в репозитории, ставить ничего не нужно. Понимает ревизии MCP с 2024-11-05 по 2025-11-25
(через `initialize`) и 2026-07-28 (без рукопожатия). История версий — в [CHANGELOG.md](CHANGELOG.md).

## Что умеет

| Инструмент | Что делает | Профили |
|---|---|---|
| `status` | к какой базе подключён, под какой ролью, профиль с его инструментами и действующие лимиты | все |
| `list_tables` | таблицы, представления и внешние таблицы, которые роль может читать, с оценкой числа строк и комментариями; не больше 200 за раз | все |
| `describe_table` | колонки с типами, `NOT NULL`, значениями по умолчанию и комментариями, ключи, таблицы, которые ссылаются на эту, и индексы | все |
| `sample_rows` | несколько строк таблицы (по умолчанию 10, не больше 50), можно выбрать колонки | `explore`, `analyst` |
| `explain_query` | план запроса без выполнения; у `analyst` — и с `ANALYZE` | `explore`, `analyst` |
| `run_select` | один запрос только на чтение: `SELECT`, `WITH … SELECT`, `VALUES`, `TABLE`, `EXPLAIN`, `SHOW`; не больше 200 строк | `analyst` |

### Профили групп

Профиль решает, какие инструменты видит агент:

- `schema` — только структура, без данных;
- `explore` — структура, образцы строк и планы запросов (по умолчанию);
- `analyst` — всё перечисленное и свободный SQL только на чтение.

Профиль задаётся при регистрации (`python3 install.py --profile analyst`) или переменной
`PG_MCP_PROFILE` в блоке `env` сервера. Неизвестное значение включает самый строгий профиль,
а `status` об этом предупреждает.

### Что запрещено

Любое изменение данных, структуры, прав, настроек и чужих сессий. Защита из трёх слоёв:

1. **Роль в PostgreSQL** — настоящая граница. Скрипт [docs/role.sql](docs/role.sql) заводит
   роль только с `SELECT` на выбранные схемы:

   ```bash
   psql -d app -v role=mcp_agent -v password='…' -v schemas=sales -v owner=app_owner -f docs/role.sql
   ```

2. **Транзакция `READ ONLY` на каждый запрос**, которая всегда откатывается. Запрос уходит одной
   командой через extended protocol, так что строку `SELECT 1; COMMIT; DROP …` PostgreSQL отвергнет.
3. **Проверка текста запроса**: пропускает только перечисленные выше команды, отвергает `INSERT`,
   `UPDATE`, `DELETE`, `MERGE`, `SELECT … INTO`, блокировки строк и функции с побочными эффектами
   (`pg_terminate_backend`, `set_config`, `dblink`, `pg_sleep` и другие) и объясняет модели причину.

Полная политика — в [ADR 0002](docs/adr/0002-read-only-sql-policy.md).

Каждый ответ инструмента укладывается в бюджет — по умолчанию 8000 символов. Локальные модели
работают с небольшим контекстом, а слишком длинный ответ может оборвать сессию агента.

## Установка

Нужен Python 3.9 или новее. На macOS он приходит вместе с Command Line Tools (их ставит git),
на Linux есть почти везде. На Windows — установщик с python.org (`py -3`) или embeddable-архив,
который распаковывается без прав администратора.

1. Склонируйте репозиторий.
2. Зарегистрируйте сервер в GigaCode. Скрипт сохранит копию настроек, пропишет сервер
   и проверит, что он запускается и видит базу:

   ```bash
   python3 install.py --profile explore
   ```

   На Windows — `py -3 install.py`, для Qwen Code — `python3 install.py --client qwen`.
3. Подключите расширение: оно даёт агенту короткий контекст и команду `/pg:setup`
   для самопроверки и починки:

   ```bash
   gigacode extensions link /путь/к/pg-mcp
   ```

4. Перезапустите GigaCode.

### Подключение и настройки

Сервер читает те же переменные, что psql: `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`,
`PGSSLMODE`, `PGSSLROOTCERT`. Если они заданы в терминале при запуске `install.py`, скрипт
перенесёт их в блок `env` сервера в `~/.gigacode/settings.json`; дальше их можно править там.

Пароль храните только в `~/.pgpass` (на Windows — `%APPDATA%\postgresql\pgpass.conf`): одна
строка `host:port:database:user:password`, права 600. Ни в настройки агента, ни в чат его
не кладите.

Настройки самого сервера, тоже через `env`:

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PG_MCP_PROFILE` | `explore` | набор инструментов |
| `PG_MCP_MAX_RESPONSE_CHARS` | `8000` | бюджет ответа в символах, не меньше 500 |
| `PG_MCP_STATEMENT_TIMEOUT_MS` | `5000` | таймаут одного запроса |
| `PG_MCP_LOG_LEVEL` | `INFO` | подробность журнала в stderr |

Проверить подключение: `python3 install.py --check` — или попросите агента проверить
подключение к базе, он вызовет `status`.
